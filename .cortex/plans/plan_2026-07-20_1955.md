## Context

- Repo currently has `mcp/create-mcp-agent.sql` (pattern for SQL file style, agent creation) and `sql/cortex-ai-functions.sql`
- The existing MCP agent in the account lives at `CORTEX_APP.PUBLIC.QLIK_MCP` with MCP server `CORTEX_APP.PUBLIC.QLIK_MCP_SERVER`
- Native Apps require: `manifest.yml`, `setup_script.sql`, and supporting files uploaded to a stage
- The goal is a self-contained example that ISVs can study, adapt, and deploy

## Implementation Steps

### Step 1: Create directory structure
```
native-apps/embedded-analytics-kit/
├── README.md
├── manifest.yml
├── setup_script.sql
├── semantic/
│   └── saas_metrics.yaml
├── agent/
│   └── agent_spec.yaml
└── scripts/
    ├── consumer_setup.sql
    └── test_agent.sql
```

### Step 2: `manifest.yml`
- App version, setup script reference, privileges requested (CREATE SEMANTIC VIEW, CREATE AGENT, warehouse usage)

### Step 3: `setup_script.sql`
- Creates app schema (`core`)
- Creates sample tables: `accounts`, `subscriptions`, `monthly_revenue`, `usage_events`
- Inserts realistic SaaS seed data (~50 rows per table)
- Creates Semantic View from staged YAML
- Creates Cortex Agent with dual-tool spec:
  - `SaaSMetrics` tool (type: `cortex_analyst_text_to_sql`) → Semantic View
  - `mcp_servers` block → consumer's Qlik MCP server (parameterized)
- Grants application roles

### Step 4: `semantic/saas_metrics.yaml`
- Semantic model defining:
  - Tables: accounts, subscriptions, monthly_revenue, usage_events
  - Metrics: MRR, ARR, churn_rate, net_revenue_retention, expansion_revenue, LTV, CAC
  - Dimensions: segment (Enterprise/Mid-Market/SMB), region, plan_tier, cohort_month
  - Time grains: monthly, quarterly
  - Relationships between tables

### Step 5: `agent/agent_spec.yaml`
- Agent instructions for dual-source orchestration
- When to use Semantic View vs Qlik MCP
- Example questions for each path

### Step 6: `scripts/consumer_setup.sql`
- Consumer admin template: grant caller privileges, connect their Qlik MCP server, register with Intelligence

### Step 7: `scripts/test_agent.sql`
- Test queries exercising both tools:
  - Pure Snowflake: "What is MRR by segment?"
  - Pure Qlik: "List my Qlik apps"
  - Hybrid: "Show churn trend and find related Qlik dashboards"

### Step 8: `README.md`
- Architecture diagram (ASCII), prerequisites, install steps, customization guide

## Verification

- `manifest.yml` syntax can be validated with `snow app validate` (if available)
- `setup_script.sql` SQL can be verified by running individual statements in a worksheet
- `saas_metrics.yaml` can be validated with `cortex reflect`
- `test_agent.sql` queries can be run post-install to verify both tool paths work

- `native-apps/embedded-analytics-kit/setup_script.sql` — Core logic: tables, semantic view, agent creation
- `native-apps/embedded-analytics-kit/semantic/saas_metrics.yaml` — Semantic model defining all metrics
- `native-apps/embedded-analytics-kit/manifest.yml` — App metadata and privilege declarations
- `native-apps/embedded-analytics-kit/scripts/consumer_setup.sql` — Consumer onboarding flow
